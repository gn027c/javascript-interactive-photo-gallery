## Project Overview
This project implements an interactive photo gallery that dynamically updates DOM elements via JavaScript event listeners:
- `onmouseover="upDate(this)"` dynamically updates the background image and descriptive text of the main display viewer `#image`.
- `onmouseout="unDo()"` resets the background image and default prompt text of the main display viewer `#image`.
- Console output confirms event triggering and parameter inspection (`alt`, `src`).
